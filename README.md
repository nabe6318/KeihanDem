# 畦畔検出マップ

1m DEM と農地の筆ポリゴンから、**水田の畦畔(法面・畦)を自動で検出**するWebGISです(GitHub Pagesで動作)。
長野県のような傾斜地の棚田・段々畑を想定しています。DEMと筆ポリゴンは**このPCのローカルファイルを読み込み**、計算はすべてブラウザの中で行います(データはどこにも送信されません)。

## 手順

1. **DEM(GeoTIFF)を読み込む**:複数のタイルをまとめて選べます(地図へのドラッグ&ドロップも可)。平面直角座標のGeoTIFF(伊那谷は VIII系 EPSG:6676)。座標系が書かれていないファイルは、系番号を聞かれます
2. **筆ポリゴンを読み込む**:GeoJSON または GeoPackage。農水省の筆ポリゴン(`land_type`:100=田、200=畑)なら、自動で「田」だけを対象にします
3. **地図を計算したい範囲に合わせて「表示範囲で計算する」**:見えている範囲のうち、DEMと筆ポリゴンが重なる所だけを計算します(上限2,500万セル ≒ 1mで25 km²)
4. 閾値を調整(計算後は数値を変えるとすぐ塗り直します)→ 結果を書き出す

## 計算の流れ

1. **農地ブロック**:筆ポリゴンを1mグリッドに焼き込み、**バッファ**(既定0.5m)だけ広げて隣り合う筆を一つの塊にします(バッファ+ディゾルブと同じ)。この中だけを計算するので、道路・水路・山林の斜面は拾いません
   - 「外周は広げない」にすると、広げたあと外側から同じ幅だけ戻します(筆の間の隙間だけ埋まる)
   - 隙間に入ったセルは、隣の筆の受け持ちになります
2. **地形の特徴**(DEMから計算)
   - **傾斜**:法面をとらえる(既定 15°以上)
   - **細い高まり(トップハット)**:標高 − オープニング(幅5mの最小値→最大値フィルタ)。畦のような細い盛り上がりだけが残り、段の縁や一様な斜面は0になる(既定 10cm以上)
   - **CS立体図**:確認用の表示(曲率 凸=赤・凹=青、傾斜=茶)
3. **分類**:農地ブロック内で、傾斜または細い高まりが閾値以上 → 畦畔、それ以外 → 田面
   - 5 m²未満の畦畔のかたまりは田面に戻す(DEMのノイズ除去)
   - 15 m²未満の平坦部は畦畔に含める(法面の小段など)

## 書き出し

| ファイル | 内容 |
|---|---|
| 筆ごとの集計(CSV) | 筆ID、筆面積、田面、畦畔(平面)、**畦畔の斜面に沿った面積**(草刈り面積の目安)、畦畔率 |
| 筆ポリゴン+集計(GeoJSON) | 元の筆ポリゴンに上の集計値を属性として付けたもの |
| 畦畔ポリゴン(GeoJSON) | 筆ごとの畦畔の形(緯度経度)。属性に筆ID・面積 |
| 分類ラスタ(GeoTIFF) | 0=農地ブロックの外、1=田面、2=畦畔、3=DEMなし(DEMと同じ座標系) |
| CS立体図(PNG) | ワールドファイル(.pgw)付き。QGISでDEMと同じ座標系を指定 |

## 検証

- 合成した棚田DEM(段の奥行き40m、法面3m・約28°、法肩の畦 幅0.8m・高さ25cm、筆境の畦 幅1m・高さ15cm、ノイズ2cm)で、既定値の検出率100%、適合率96%(畦畔面積は真値の約1.05倍)
- 畦畔ポリゴンの面積は分類ラスタの面積と0.5%以内で一致
- 1m DEM 約570万セル・38筆で約6秒

## 注意

- DEMは地表面の高さです。法面の草丈・樹木・ハウス、農道や水路の段差も地形として拾います。航空写真と見比べてください
- 畦の高さが10cmに満たない平地の水田や、DEMのノイズ(測量の縞など)が大きいデータでは閾値の調整が必要です
- 複数のDEMタイルは同じ座標系・解像度にそろえてください

## 公開・ローカル確認

1. GitHubで新しいリポジトリ(例 `AzeDetect`、Public)を作り、`index.html`・`README.md`・`tools` をアップロード
2. 「Settings」→「Pages」→ `main` / `/(root)` →「Save」
3. ローカルで確認:`python tools/serve.py` → `http://localhost:8000`

`index.html` の `CONFIG` で、起動時の地図の位置・閾値の既定値・計算範囲の上限を変えられます。
